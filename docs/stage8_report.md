# Stage 8 — PDF Report Generation

## Overview

The PDF report module generates a supervisor-grade daily safety report
from the event log. It uses reportlab to produce a multi-section PDF
with tables, metrics, summaries, and recommendations.

## PDF Sections

1. **Header** — Site name, date, report generation timestamp
2. **Executive Summary** — Total scans, violations, compliance rate, most unsafe zone
3. **Zone-Wise Violation Table** — All 6 zones with scans, violations, compliance %
4. **PPE Violation Breakdown** — Per-PPE-type violation counts
5. **Zone Hotspot Ranking** — Top 3 most unsafe zones with violation rates
6. **Incident Log** — Recent 20 violations (timestamp, zone, missing PPE, severity)
7. **Supervisor Summary** — Natural-language narrative (LLM via OpenRouter if key set, otherwise rule-based)
8. **Recommendations** — Actionable suggestions based on violation patterns
9. **Footer** — Generated by AI Construction Safety Monitor, disclaimer

## Summary Generation

### Rule-Based (Default)

`summary_generator.py` generates a 3-4 paragraph summary from metrics:
- Paragraph 1: Overview (scans, violations, compliance, severity breakdown)
- Paragraph 2: Zone analysis (violation distribution)
- Paragraph 3: PPE analysis (most common missing items)
- Paragraph 4: Overall assessment (based on compliance rate thresholds)

### LLM-Based (Optional)

If `OPENROUTER_API_KEY` is set in `.env`, the summary uses GPT-4o-mini
via OpenRouter. The LLM receives structured metrics as JSON and generates
a narrative. Falls back to rule-based if the API call fails.

## Recommendation Rules

| Condition | Recommendation |
|-----------|----------------|
| Compliance < 70% | URGENT: Site-wide safety review |
| Compliance < 90% | Targeted safety briefings |
| Most unsafe zone | Increase monitoring in that zone |
| Most common missing PPE | Conduct compliance briefing for that PPE |
| High-severity violations | Address immediately |
| 4+ zones with violations | Systemic issue — site-wide stand-down |
